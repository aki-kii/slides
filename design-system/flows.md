# 構成の型

ページの並べ方（話の流れ）の型。[全体の型（テーマ）](themes.md) が、どれを背骨にするかを選ぶ。どのデッキも [全体の骨組み](#flow-whole) の上に、テーマの流れを1つか2つ乗せる。

| ID | 名前 | 背骨にするテーマ |
|---|---|---|
| flow-whole | 全体の骨組み | すべて |
| flow-analyze-improve-review | 分析 → 改善 → 振り返り | 検証してみた系 |
| flow-trouble-solution | 困りごと → 解決策 | 入門・紹介系 |
| flow-onayami | お悩みを1つずつ解決 | プラクティス紹介系 |
| flow-part-intro | 部の頭に導入の紙芝居 | 入門・紹介系、体験談系 |
| flow-definition-return | 定義に戻りながら進める | 解説系 |
| flow-question-answer | 疑問を湧かせてから解消する | 解説系 |

---

## flow-whole 全体の骨組み

- **何の型か**: [表紙](pages.md#page-title) → [自己紹介](pages.md#page-profile) → 導入 → 本編 → まとめ →（[宣伝](pages.md#page-promo)）→ [Thank You](pages.md#page-thanks)
- **いつ使うか**: すべてのデッキ
- **写真**: ecr-sbom の p.1 表紙 → p.2 自己紹介 → p.3 導入 → p.5・8・9 本編 → p.13 まとめ → p.18 Thank You

## flow-analyze-improve-review 分析 → 改善 → 振り返り

- **何の型か**: 各パートは「最初に時間がかかっているポイントを分析し、そのポイントを改善したらどうなったか？を振り返る」の繰り返し（コンテナ支部、2026-11-14 本人）
- **いつ使うか**: 何かを改善した話。改善の手段は役割を先に言い、解説はその直後に置く。最初の分析にあとで比べる項目を入れておき、振り返りでは同じ項目同士を並べる。悪くなった所も見せる（2026-11-15）
- **写真**: container-31 の p.7 分析 → p.8 手段 → p.9・11 解説 → p.12 適用 → p.13 振り返り
- **写真の注記**: 代わりになるデッキが無いので、まだ直す余地のある jawsug-container-31 の帯をこの1枚だけ使っている。デッキが固まったら撮り直す

## flow-trouble-solution 困りごと → 解決策

- **何の型か**: 導入で困りごとを見せ、問題点を並べてから、解決策の話に入る（初心者支部、本人「こんなことに困ってない？？ってきいて解決策を出す方が刺さりそう」2026-10-24）
- **いつ使うか**: 入門や紹介の話で、聞く人に「自分のことだ」と思ってもらいたいとき
- **写真**: bgnr-93 の p.5〜7 ストーリー → p.10 問題点 → p.11 章扉

<!-- shots:flow-trouble-solution -->

## flow-onayami お悩みを1つずつ解決

- **何の型か**: 章扉（「① 〜するべし」）→ お悩み → 解決、をプラクティスの数だけ繰り返す
- **いつ使うか**: いくつかのプラクティスを紹介する話（cdk-day1）。life に記録はなく、デッキから拾った型
- **写真**: cdk-day1 の p.10 → p.11 章扉 → p.12 お悩み → p.13 解決

<!-- shots:flow-onayami -->

## flow-part-intro 部の頭に導入の紙芝居

- **何の型か**: 部を1段上に置き、各部の最初に章扉と紙芝居を入れる（LT #40、2026-10-19 本人と決定）
- **いつ使うか**: 部がいくつかあるデッキ。紙芝居はデッキの導入と、この各部の導入で使う（[決めたこと](decisions.md#q2)）
- **写真**: zero-drift の p.20 章扉 → p.21 紙芝居 → p.22 一覧 → p.23 章扉

<!-- shots:flow-part-intro -->

## flow-definition-return 定義に戻りながら進める

- **何の型か**: [定義の使い回し](pages.md#page-definition-reuse) のページを章の区切りに置き、話を定義に戻しながら進める（CDK 支部×東京支部の発表、2026-11）
- **いつ使うか**: 1つの定義を深掘りする話
- **写真**: cdkd-talk の p.3 → p.7 → p.12 → p.17 → p.21

<!-- shots:flow-definition-return -->

## flow-question-answer 疑問を湧かせてから解消する

- **何の型か**: 説明のあとに「何故そこまでして〜？」のページを置き、聞く人に湧いた疑問にすぐ答える（茨城 #17、2026-09-28）
- **いつ使うか**: 説明を聞いた人が「なぜ？」と思いそうなとき
- **写真**: 疑問のページそのもの（continuum p.11）。前後のページは図が崩れて写るため帯にしていない
