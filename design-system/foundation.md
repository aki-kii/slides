# 土台

全ページに共通する決まり。色、文の書き方、図のスタイル、サイズの4つ。デッキの名前の付け方は [デッキの名前（提案）](naming.md) にある。

## base-color 色

- **何の型か**: 文字は濃い紺、強調は赤の太字、表紙と最後のページは青のグラデーション。表紙のキーワードだけ黄色
- **いつ使うか**: 全ページ。色は意味で使い、同じ意味には同じ色（diagram-style.md）
- **写真**: continuum p.20（紺の文字と赤の強調）、lt-40 p.1（青のグラデーションと黄色のキーワード）

デッキの `style.css` で使っている値（bgnr-93・continuum の `:root`、表紙の `layouts/`）:

| 役割 | 値 | 白地とのコントラスト |
|---|---|---|
| 文字（濃い紺） `--ink` | `#2c3e50` | 11.0:1 |
| 文字（やや薄い） `--ink-soft` | `#34495e` | 9.3:1 |
| 文字（薄い） `--ink-mute` | `#7f8c8d` | 3.5:1（補足には足りない。下のサイズの決まりを参照） |
| 強調（赤） `--accent-warm` | `#e74c3c` | 3.8:1（太字かつ 24px 以上なので「大きい文字」の 3:1 を満たす） |
| リンク・ブランド `--brand` | `#3498db` | — |
| 表紙・最後のページのグラデーション | `linear-gradient(155deg, #015d7d 0%, #0283b2 60%, #1aa9d1 100%)` | 白い文字は濃い側 7.3:1、明るい側 2.8:1 |

図の中の色は diagram-style.md の表に従う（[図のスタイル](#base-diagram)）。

## base-text 文の書き方

- **何の型か**: 見出しは名詞句。見出しとリード文は「だ・である」調、紙芝居と字幕は話し言葉（初心者支部、2026-10-29）。主語を抜かない。英語と日本語の間に空白を入れない。例示は「e.g.」。「CFn」と略さない。文字は1行に収める。表と絵文字は使わない
- **いつ使うか**: 全ページ
- **写真**: なし（決まりだけ）

資料を直すときの5つの目線（SKILL.md、2026-10-22）。下の決まりはどれかの目線から来ている。

1. 聞く人の頭の中から見る
2. 盛らずに、正直に見せる
3. 自分の言葉で語る
4. 見て一瞬でわかるか（文より図、1枚に言いたいことは1つ。足すより引く）
5. 全体でそろっているか、次にも使えるか

## base-diagram 図のスタイル

- **何の型か**: 手で組んだ SVG。流れは左から右。角丸の薄い塗りのグループ枠と白い箱、AWS のアイコン、主語のある短いラベルの矢印（diagram-style.md。本人「かなり自分の好み」）
- **いつ使うか**: 仕組みや流れを見せるとき。「文より図」（5つの目線の4）
- **詳しい決まり**: life の `tasks/speaking/diagram-style.md`（色の表、形、矢印と線、アイコン、文字）。スライドには `<img>` ではなく `InlineSvg` で埋め込む
- **写真**: jaws-sonic-2026 p.6、lt-40 p.9、lt-40 p.13、zero-drift p.4

## base-size サイズ

人が会場でスライドを見たときに読める大きさを、規範として決めたもの。今のデッキがこの通りになっている必要はない。次に作るデッキと、直すページから合わせる。根拠と出典は [サイズの調査メモ](research-sizes.md) にある。

### 前提: 画面の大きさと単位

- Slidev の画面（キャンバス）は幅 980px、縦横比 16:9 で高さ 552px（Slidev の既定値）。下の px はこの画面の上での大きさ
- PowerPoint のワイド画面（13.333 × 7.5 インチ ＝ 960 × 540pt）とほぼ同じ大きさなので、**1pt ≒ 1px** と読み替えてよい
- 本人のデッキは `style.css` で `:root { font-size: 20px }` にしているので、**1rem ＝ 20px**

### 文字の大きさ

| 役割 | 大きさ | rem（1rem＝20px） | 例 |
|---|---|---|---|
| 表紙のタイトル | 40〜48px | 2〜2.4rem | [表紙](pages.md#page-title) |
| 言い切り | 36〜44px | 1.8〜2.2rem | [紙芝居型](pages.md#page-kamishibai) の言い切り、[まとめ（言い切り）](pages.md#page-summary-statement)、[章扉](pages.md#page-chapter)、[Q&A](pages.md#page-qa) |
| 見出し | 36px（32px を下限） | 1.8rem | 各ページの見出し |
| 本文 | 24px を下限（LT は 28px 以上を目指す） | 1.2rem | リード文、箇条書き、カードの中、「→」の1行、Overlay の一言、字幕帯 |
| 補足 | 18px を下限（20px を勧める） | 0.9〜1rem | [小声](parts.md#part-kogoe)、前置き、図のラベル、注記 |
| 例外: 読ませない文字 | 12〜14px | 0.6〜0.7rem | [出典のリンク](parts.md#part-bottomlink) |

- 行の間は本文で 1.5 倍
- 1枚の本文は8行まで。文字は1行に収める（[文の書き方](#base-text)）。本文 24px で左右の余白を引くと、1行は全角でおよそ35字
- 例外の文字には、話の中身を載せない。会場で読めなくても話が通じるものだけにする

### 文字と背景のコントラスト

| 文字 | 下限 |
|---|---|
| 本文・見出し | 7:1 以上 |
| 補足（小声など、薄くした文字） | 4.5:1 以上 |
| 24px 以上の太字の強調 | 3:1 以上 |

- 今の値で足りないもの: 小声（`Kogoe`、紺を 50% に薄めて約 2.7:1）、出典の題名（約 2.6:1）。小声は補足として読ませるので、次に `@slides/ui` を直すときに 4.5:1 まで濃くする（`#6b7684` で 4.6:1）。出典は読ませない文字の例外
- 表紙のグラデーションの明るい側（`#1aa9d1`）に白い文字を置くと 2.8:1 になる。文字はグラデーションの濃い側（左上）に置く

### アイコン

| 置き場所 | 大きさ（画面の上） |
|---|---|
| [アイコン付きの見出し](parts.md#part-icon-heading) | 見出しの文字の高さ ＋ 少し（36〜40px） |
| 図の主役のサービス | 48px 以上 |
| 図のグループ枠の左上 | 24px 以上 |

### 図の中の文字

- 図は `viewBox="0 0 1000 H"` で描き、画面の左右の余白を引いた幅（840px）に縮んで入る。図の中の 1 は画面の約 0.84px
- そのため図の中の文字は viewBox の単位で **22 以上**（画面で約 18px、補足の下限）にする。箱の名前など読ませたい文字は 28 以上（画面で約 24px）
- diagram-style.md の文字の大きさ（ラベル 12〜15px、箱の名前 14〜18px、補足 11〜13px）は、この規範より小さい。新しい図はこの規範に合わせ、文字が入らないときは言葉を縮めるか図を分ける（diagram-style.md「図の中で文字がはみ出したら、箱を広げるか言葉を縮める」）

### 余白

- 画面の端からの余白は 左右 70px・上下 50px。Slidev の既定（`px-14 py-10`）を 1rem＝20px で計算した値で、本人のデッキの値
- 中身はこの内側に置く。「→」の1行、出典のリンク、字幕帯もこの内側（字幕帯の帯の背景だけは端まで伸ばしてよい）
- 図の余白は diagram-style.md の通り「カスタムリソースとは？」の図くらい
