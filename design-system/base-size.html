サイズ base-size

人が会場でスライドを見たときに読める大きさを、規範として決めたもの

いつ使うか #

全ページ。今のデッキがこの通りになっている必要はない。次に作るデッキと、直すページから合わせる

値 #

根拠と出典は サイズの調査メモ にある。

前提: 画面の大きさと単位 #

  • Slidev の画面（キャンバス）は幅 980px、縦横比 16:9 で高さ 552px（Slidev の既定値）。下の px はこの画面の上での大きさ
  • PowerPoint のワイド画面（13.333 × 7.5 インチ ＝ 960 × 540pt）とほぼ同じ大きさなので、1pt ≒ 1px と読み替えてよい
  • 本人のデッキは style.css で :root { font-size: 20px } にしているので、1rem ＝ 20px

文字の大きさ #

役割大きさrem（1rem＝20px）例
表紙のタイトル40〜48px2〜2.4rem表紙
言い切り36〜44px1.8〜2.2rem紙芝居型 の言い切り、まとめ（言い切り）、章扉、Q&A
見出し36px（32px を下限）1.8rem各ページの見出し
本文24px を下限（LT は 28px 以上を目指す）1.2remリード文、箇条書き、カードの中、「→」の1行、Overlay の一言、字幕帯
補足18px を下限（20px を勧める）0.9〜1rem小声、前置き、図のラベル、注記
例外: 読ませない文字12〜14px0.6〜0.7rem出典のリンク
  • 行の間は本文で 1.5 倍
  • 1枚の本文は8行まで。文字は1行に収める（文の書き方）。本文 24px で左右の余白を引くと、1行は全角でおよそ35字
  • 例外の文字には、話の中身を載せない。会場で読めなくても話が通じるものだけにする

文字と背景のコントラスト #

文字下限
本文・見出し7:1 以上
補足（小声など、薄くした文字）4.5:1 以上
24px 以上の太字の強調3:1 以上
  • 今の値で足りないもの: 小声（Kogoe、紺を 50% に薄めて約 2.7:1）、出典の題名（約 2.6:1）。小声は補足として読ませるので、次に @slides/ui を直すときに 4.5:1 まで濃くする（#6b7684 で 4.6:1）。出典は読ませない文字の例外
  • 表紙のグラデーションの明るい側（#1aa9d1）に白い文字を置くと 2.8:1 になる。文字はグラデーションの濃い側（左上）に置く

アイコン #

置き場所大きさ（画面の上）
アイコン付きの見出し見出しの文字の高さ ＋ 少し（36〜40px）
図の主役のサービス48px 以上
図のグループ枠の左上24px 以上

図の中の文字 #

  • 図は viewBox="0 0 1000 H" で描き、画面の左右の余白を引いた幅（840px）に縮んで入る。図の中の 1 は画面の約 0.84px
  • そのため図の中の文字は viewBox の単位で 22 以上（画面で約 18px、補足の下限）にする。箱の名前など読ませたい文字は 28 以上（画面で約 24px）
  • diagram-style.md の文字の大きさ（ラベル 12〜15px、箱の名前 14〜18px、補足 11〜13px）は、この規範より小さい。新しい図はこの規範に合わせ、文字が入らないときは言葉を縮めるか図を分ける（diagram-style.md「図の中で文字がはみ出したら、箱を広げるか言葉を縮める」）

余白 #

  • 画面の端からの余白は 左右 70px・上下 50px。Slidev の既定（px-14 py-10）を 1rem＝20px で計算した値で、本人のデッキの値
  • 中身はこの内側に置く。「→」の1行、出典のリンク、字幕帯もこの内側（字幕帯の帯の背景だけは端まで伸ばしてよい）
  • 図の余白は diagram-style.md の通り「カスタムリソースとは？」の図くらい
