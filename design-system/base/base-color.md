文字は濃い紺、強調は赤の太字、表紙と最後のページは青のグラデーション。表紙のキーワードだけ黄色

## 見本

<!-- shots:base-color -->

continuum p.20（紺の文字と赤の強調）、lt-40 p.1（青のグラデーションと黄色のキーワード）

## いつ使うか

全ページ。色は意味で使い、同じ意味には同じ色（diagram-style.md）

## 中身

デッキの `style.css` で使っている値（bgnr-93・continuum の `:root`、表紙の `layouts/`）:

| 役割 | 値 | 白地とのコントラスト |
|---|---|---|
| 文字（濃い紺） `--ink` | `#2c3e50` | 11.0:1 |
| 文字（やや薄い） `--ink-soft` | `#34495e` | 9.3:1 |
| 文字（薄い） `--ink-mute` | `#7f8c8d` | 3.5:1（補足には足りない。[サイズ](@base-size) を参照） |
| 文字（補足） `--ink-note` | `#6b7684` | 4.6:1（[サイズ](@base-size) で小声・注記に使う値。container-31 の `style.css` で使用） |
| 強調（赤） `--accent-warm` | `#e74c3c` | 3.8:1（太字かつ 24px 以上なので「大きい文字」の 3:1 を満たす） |
| リンク・ブランド `--brand` | `#3498db` | — |
| 表紙・最後のページのグラデーション | `linear-gradient(155deg, #015d7d 0%, #0283b2 60%, #1aa9d1 100%)` | 白い文字は濃い側 7.3:1、明るい側 2.8:1 |

図の中の色は diagram-style.md の表に従う（[図のスタイル](@base-diagram)）。
